# StudyMate AI

StudyMate AI is a student-first productivity app built to help learners organize notes, understand complex subjects, and prepare for exams with guided practice.

## Features

- Upload and organize notes
- AI-style concept summaries for study material
- Subject-based progress tracking
- Daily task planner
- Practice quiz generation
- Performance analytics dashboard
- Responsive modern UI for student workflows

## Stack

- React
- TypeScript
- Vite

## Run locally

```bash
npm install
npm run dev
```

Then open:

```bash
http://localhost:3000
```

## Product flow

Upload → Understand → Practice → Test → Analyze → Improve

This version is a frontend-only product prototype that simulates the full app experience in-browser using local storage and interactive study tools.
